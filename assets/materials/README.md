# Builder materials

`manifest.json` describes the categories, materials and their image variants. Paths in `variants[].file` are relative to this directory. Replace an SVG placeholder with a transparent PNG or WebP and update its file path, or add another variant entry with a unique `id` and optional `colour`. A longest side around 512 px is recommended; keep transparent padding consistent across variants. `w` and `h` describe the intrinsic proportions, `defaultScale` controls its initial size, and `zHint` suggests its layer. `anchor` is the attachment point as fractions of the image width and height, and `snap` selects the matching attachment region. Add translated names and keywords for all three languages. Files are loaded only when their category or a saved scene needs them. The manifest can be edited directly for custom artwork; running `tools/make_materials.py` regenerates its placeholder contents.
